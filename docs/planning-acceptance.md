# Проверка новых функций

1. В «Бюджет и платежи» выбрать месяц и добавить лимит. Записать расход в эту категорию. При 80% появляется предупреждение, при превышении — сумма перерасхода. Редактирование и удаление лимита не меняют операции.
2. Добавить ежемесячный платёж на 31 января. Подтверждение расхода должно создать одну операцию, перенести дату на конец февраля, затем на 31 марта. Повторное подтверждение старой даты не создаёт вторую операцию. Пауза выключает напоминание.
3. В «Быстрый расход» сохранить любимые категории, записать сумму за сегодня. «Повторить последнюю операцию» открывает форму с новой датой; запись появляется только после сохранения.
4. В аналитике выбрать месяц: сравнение показывает доходы, расходы, разницу доходов и расходов, изменения категорий относительно прошлого месяца. Незавершённый месяц явно обозначен в пояснении.
5. Загрузить CSV, выбрать столбцы, проверить предпросмотр. Одна неверная строка блокирует импорт. При повторном импорте того же содержимого количество операций не увеличивается. Шаблон содержит пример, который надо заменить своими записями.
6. В настройках открыть инструкции установки. Проверить manifest, иконки и service worker. Установка на реальный телефон проверяется после размещения на HTTPS; локальная машина не становится доступной телефону через 127.0.0.1. Офлайн показывается только сообщение, приватные данные не кешируются.

Тестовые аккаунты и синтетические операции создаются только автоматическими тестами; реальные аккаунты не заполняются демонстрационными данными.

Автоматизация: `tests/unit/planning.test.ts`, `tests/e2e/planning.spec.ts` и прежние проверки `tests/e2e/app.spec.ts`. Для маломощного компьютера запускать Vitest с `--maxWorkers=1 --no-file-parallelism`; не запускать сборку и браузерные тесты одновременно.
